Case Study / Security Solution QA

39개 제품의 반복 품질검사를 위한 QA Harness 구축

2024.10 - PresentSecurity Solution QA

품질검사 Workflow를 연결하고 자동화 결과의 Validation Gate를 구성한 사례입니다.

Background

39개 제품의 반복 품질검사를 수행하며 문서 검토, Test Case 생성, 테스트 실행, 결과 작성 단계가 이어졌습니다.

Problem

반복되는 품질검사 Workflow를 자동화하면서, 잘못 생성된 결과물이 다음 단계로 넘어가지 않도록 검증할 필요가 있었습니다.

Analysis

규칙 기반 처리와 제품 Context에 기반한 QA 판단 영역을 분리했습니다.

QA Strategy

39개 제품의 품질검사 Workflow를 연결하는 QA Harness를 설계하고, 자동화 결과를 다시 검증하는 Validation Gate를 구성했습니다.

Action

문서 검토 → Test Case 생성 → 테스트 실행 → 결과 작성을 하나의 Workflow로 연결하고, QA Harness를 직접 설계 및 구축했습니다.

Result

실제 요청에서 잘못 생성된 결과물 2건을 다음 단계 전에 차단했습니다. 반복 업무를 자동화해 제품 이해, 변경 영향도 분석, 주요 Risk 검증에 집중할 수 있는 구조로 개선했습니다.
