예약 거래 E2E 검증

POING CORPORATIONQA Senior2022.08 - 2024.09

5개 예약 채널의 거래가 백엔드를 거쳐 매장 앱에 반영되는지 검증했습니다.

예약 채널
5개
검증 범위
E2E 데이터 흐름
  1. 5개 예약 채널
  2. 백엔드
  3. 매장 앱

배경

B2C 고객 앱은 네이티브, B2B 매장 앱은 하이브리드 방식입니다. 5개 예약 채널의 거래가 백엔드를 거쳐 매장 앱에 반영되는 흐름을 검증했습니다.

문제

외부 채널에서는 예약이 성공했지만, 백엔드 전달이 누락돼 매장 앱에 반영되지 않았습니다.

분석

채널의 예약 성공 여부와 매장 앱의 반영 여부를 함께 확인해야 했습니다.

QA 전략

5개 채널 각각에서 예약 생성부터 매장 앱 반영까지 E2E 검증 범위를 정했습니다.

실행

예약 생성, 백엔드 전달, 매장 앱 반영을 순서대로 확인했습니다.

결과

외부 채널에서는 예약이 성공했지만 백엔드 전달이 누락되는 이슈를 발견했습니다.
