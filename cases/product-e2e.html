Case Study

예약 거래 E2E 검증

POING CORPORATIONQA Senior2022.08 - 2024.09

예약 채널의 성공 결과가 매장 App까지 이어지는지 E2E로 검증한 사례입니다.

예약 채널
5개
검증 범위
E2E Data Flow
  1. 5개 예약 채널
  2. Backend
  3. 매장 App

Background

Native 기반 B2C 예약 App과 Hybrid 기반 B2B 매장 App을 대상으로, 5개 예약 채널에서 생성된 거래가 Backend를 거쳐 매장 App에 반영되는 흐름을 검증했습니다.

Problem

외부 예약 채널에서는 예약이 성공했지만 Backend 전달이 누락되어 매장 App에 반영되지 않는 Issue가 있었습니다.

Analysis

예약 채널의 성공 결과와 매장 App의 반영 결과를 연결해 확인해야 하는 거래 흐름으로 보았습니다.

QA Strategy

5개 예약 채널 각각에서 예약 생성부터 Backend, 매장 App까지 이어지는 E2E 검증 범위를 설정했습니다.

Action

예약 생성 → Backend 전달 → 매장 App 반영 순서로 거래 흐름을 검증했습니다.

Result

외부 채널에서는 성공했지만 Backend 전달이 누락되어 매장 App에 반영되지 않는 Issue를 발견했습니다.
