Case Study / Product / Service QA

제품 특성에 따른 Release / Regression 전략

2022.08 - 2024.09Product / Service QA

배포 특성과 영향도를 기준으로 Release, Hotfix, Regression 범위를 판단한 사례입니다.

Background

B2C 예약 App은 Native, B2B 매장 App은 Hybrid 방식으로 운영되며, 2주 단위 Release에서 각 배포 특성을 고려해야 했습니다.

Problem

Release와 Hotfix를 판단할 때 사용자와 비즈니스 영향뿐 아니라 우회 가능 여부와 배포 제약을 함께 고려해야 했습니다.

Analysis

B2C Native와 B2B Hybrid의 배포 특성, 사용자 영향, 비즈니스 영향, 우회 가능 여부, 배포 제약을 판단 기준으로 정리했습니다.

QA Strategy

제품 특성과 영향도를 기준으로 Hotfix 여부를 판단하고, Production Issue 및 반복 Issue를 Regression에 반영하는 방향으로 접근했습니다.

Action

2주 단위 Release에 맞춰 배포 특성을 고려하고, Production Issue와 반복 Issue를 Regression 범위에 반영했습니다.

Result

Hotfix 판단 기준과 Production Issue 및 반복 Issue를 반영한 Regression 전략을 적용했습니다.
