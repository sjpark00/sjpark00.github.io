Case Study / Security Solution QA

약 4,000개 API 조합을 5일에서 20분으로

2024.10 - PresentSecurity Solution QA

Data-driven API Automation을 4개 검사 회차에 재사용한 사례입니다.

Background

고객 환경에 구축되는 보안 솔루션의 품질검사에서 약 4,000개 API 조합을 검증해야 했습니다.

Problem

약 4,000 Cases를 검사하는 데 약 5일이 걸렸습니다.

Analysis

반복되는 API 조합을 Data-driven 방식으로 다룰 수 있는 검증 대상으로 보았습니다.

QA Strategy

Postman / Newman을 사용해 Data-driven API Automation을 구성했습니다.

Action

약 4,000 Cases의 API 조합을 자동화하고, 4개 검사 회차에 재사용했습니다.

Result

약 5일 걸리던 검증을 약 20분으로 줄였고, 동일한 자동화를 4개 검사 회차에 재사용했습니다.
